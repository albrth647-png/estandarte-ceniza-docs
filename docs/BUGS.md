# Registro de bugs (DoD: un ALTA abierto bloquea)

> Formato obligatorio (`AGENTS.md` / `PLAN_FASES_DEMO.md`):
> `ID | fecha | pantalla | pasos | esperado | actual | ALTA/MEDIA/BAJA | ABIERTO→EN CURSO→ARREGLADO→VERIFICADO`

## Como se usa

1. **Reproducir antes de abrir:** pasos numerados, en el movil del dueno y en escritorio.
2. **Severidad:** `ALTA` bloquea el paso de fase · `MEDIA` lleva fecha · `BAJA` se anota y sigue.
3. **Estados:** `ABIERTO` → `EN CURSO` → `ARREGLADO` → `VERIFICADO` (solo el dueno verifica).
4. Cierre de fase: **0 ALTA, ≤5 MEDIA con fecha** (`08_QA.md` §Pre-publicacion).
5. Cada bug cerrado deja su nota en el doc de la pantalla afectada si cambio un comportamiento.
